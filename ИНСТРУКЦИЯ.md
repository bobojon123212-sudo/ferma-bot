# 📱 Приложение «Ферма» для Android

Приложение работает с **той же базой**, что и Telegram-бот: всё, что записано в приложении,
сразу видно в боте, и наоборот. Вход — по коду, который бот присылает в Telegram.
Войти могут только пользователи из списка бота.

## Что в архиве

| Файл / папка | Что это |
|---|---|
| `bot.py` | Ваш бот + API для приложения. Вся старая логика бота не изменена. |
| `webapp/index.html` | Интерфейс приложения (сервер отдаёт его по адресу `/app`). |
| `android/` | Android-проект (APK). |
| `.github/workflows/build-apk.yml` | Автосборка APK на GitHub. |

## Шаг 1. Обновить бота на Render

1. В репозитории, из которого Render запускает бота, замените `bot.py` новым файлом.
2. Добавьте рядом папку `webapp` (с файлом `index.html`).
3. Сделайте commit — Render сам перезапустит бота.
4. Проверка: откройте в браузере `https://ВАШ-АДРЕС.onrender.com/app` — должен открыться вход в приложение.

Новых библиотек ставить не нужно — всё уже есть в `requirements.txt` бота.

## Шаг 2. Собрать APK (бесплатно, через GitHub)

1. Загрузите в тот же репозиторий папки `android` и `.github`
   (на сайте GitHub: **Add file → Upload files**, перетащите папки).
   > Если папка `.github` не загрузилась (на компьютере она может быть скрыта):
   > **Add file → Create new file**, имя `.github/workflows/build-apk.yml`, вставьте содержимое файла.
2. *(Необязательно)* Чтобы приложение не спрашивало адрес сервера:
   **Settings → Secrets and variables → Actions → Variables → New variable**,
   имя `SERVER_URL`, значение `https://ВАШ-АДРЕС.onrender.com`.
3. Откройте вкладку **Actions → «Собрать APK» → Run workflow**.
4. Через 3–5 минут откройте завершённую сборку и внизу скачайте **Ferma-APK** (zip, внутри `Ferma.apk`).

## Шаг 3. Установить на телефон

1. Перекиньте `Ferma.apk` на телефон (например, через Telegram «Избранное»).
2. Откройте файл → разрешите «Установка из неизвестных источников».
3. При первом запуске введите адрес сервера (если не задали `SERVER_URL`).
4. Введите свой Telegram ID → бот пришлёт 4-значный код → вход выполнен.

Новые версии APK ставятся поверх старой без удаления (подпись всегда одна и та же).

## Что умеет приложение

- 🏠 Главная: всего вложено, расход за сегодня и месяц, предупреждения «мало корма»
- 🐄 Коровы: активные и проданные (с прибылью/убытком), карточка коровы, фото
- ➕ Записать расход (на одну или на всех), продать, добавить корову
- 🏪 Склад: купить корм, списать (стоимость делится на всех коров, как в боте)
- 📆 Отчёты: за сегодня, по месяцам (можно листать), за всё время
- 🗂 Товары, 👥 Пользователи (только для владельца)

## Важно знать

- **Render (бесплатный тариф) засыпает** через 15 минут без активности. Первый запуск
  приложения после сна может занять до минуты — это нормально.
- Фото, добавленные из приложения, хранятся в Telegram: бот отправит фото вам в чат
  (так же, как при добавлении через бота).
- Файл `android/app/ferma.jks` — ключ подписи APK. Не удаляйте его, иначе обновления
  придётся ставить с удалением старой версии. Лучше держать репозиторий **приватным**.
- Приложение работает только когда бот запущен на Render (режим webhook).
